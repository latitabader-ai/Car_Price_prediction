# توقع أسعار السيارات المستعملة في السعودية

مشروع تعلّم آلة كامل يتنبأ بسعر السيارة المستعملة (بالريال السعودي) بناءً على خصائصها — الماركة، الموديل، سنة الصنع، المسافة المقطوعة، سعة المحرك، الحالة، تاريخ الحوادث، وغيرها.

## المحتوى

- **`Final_Project.ipynb`** — النوتبوك الكامل: تنظيف البيانات، تحليل استكشافي (EDA)، بناء pipeline للمعالجة، تدريب ومقارنة ثلاثة نماذج، تحليل أهمية المتغيرات، وتطبيق Streamlit تفاعلي للتنبؤ.
- **`day5_car_prices.csv`** — بيانات 1000 عملية بيع سيارة بـ 18 خاصية.

## أبرز النتائج

| النموذج | MAE | RMSE | R² |
|---|---:|---:|---:|
| Linear Regression | 24,547 | 35,400 | 0.744 |
| Decision Tree | 13,755 | 19,577 | 0.922 |
| **Random Forest** | **10,666** | **16,579** | **0.944** |

أهم ثلاثة عوامل مؤثرة على السعر: **سعة المحرك**، **سنة الصنع**، و**المسافة المقطوعة**.

## التقنيات

Python · pandas · scikit-learn (Pipeline, ColumnTransformer, RandomForestRegressor) · seaborn/matplotlib · Streamlit

## التشغيل

```bash
pip install -r requirements.txt
jupyter notebook Final_Project.ipynb
```

لتشغيل تطبيق التنبؤ التفاعلي، نفّذي خلايا النوتبوك حتى تدريب النموذج، ثم:

```bash
streamlit run app.py
```
